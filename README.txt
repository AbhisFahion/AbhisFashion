# AbhisFashion website

Free static website starter for AbhisFashion.

Files:
- index.html — website
- style.css — design
- script.js — WhatsApp ordering
- images/ — uploaded product images

To publish for free:
1. Create a GitHub account.
2. Create a PUBLIC repository named `abhisfashion`.
3. Upload all files while keeping the `images` folder.
4. Open Settings → Pages.
5. Select Deploy from branch → main → /(root) → Save.
6. Your free site will appear at a GitHub Pages URL.

Before publishing, replace the sample product prices/sizes with the real stock information.
